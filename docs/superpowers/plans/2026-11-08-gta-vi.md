# GTA VI Appearance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a selectable GTA VI appearance using a fixed official screenshot and reference-inspired colors and lettering.

**Architecture:** Extend the existing Skin catalog and immutable font selection. Isolate wallpaper loading and rendering from recommendation thumbnails and system launcher control. Preserve the existing two skins and their persisted IDs.

**Tech Stack:** Java, Android Canvas, existing Bash build, Android SDK 34 and JDK 17.

**Spec:** docs/superpowers/specs/2026-11-08-gta-vi-design.md (scope extended and authorized by user request to add the GTA VI screensaver).

## Global Constraints
- Android 12+; Portuguese/English UI; no Gradle or new runtime dependencies.
- No TV mutation or installation; installed signature and settings preservation remain unverified.
- Preserve MIT, upstream/fork credits and asset licenses. Attribute Rockstar screenshot separately.
- Do not change HomeMode, Adb, ModeJob, Watchdog or package protections.

## Review Focus
- Saved unknown/old skin IDs must continue to resolve safely.
- Background decoding failure must leave readable controls.
- Large input images must not allocate full source resolution on the UI thread.
- Leaving/reopening the activity during loading must not publish stale image state.
- Switching skins must not leak fonts, palettes or wallpaper into the original skins.
