# Xbox game panel — requested home integration

User approved the game panel beside the existing countdown, navigable to find other games in their Xbox account, with emojis matching each metric and game artwork beside the name. Read-only PC tests succeeded against OpenXBL: Far Cry3 Classic Edition is available; achievements and MinutesPlayed were returned. Personal test values/account/key are not embedded as app defaults or public fixtures.

Implement a compact panel to the right of the countdown and before the existing corner buttons. It displays the selected game's Xbox artwork/name, 🏆 achievements, ⏱️ playtime and 📊 achievement completion. OK opens a native remote-friendly Xbox page with search, paged game rows each with artwork, selection/details, refresh and connection controls. Details include additional reported game stats with meaningful emojis (🎯 headshots, 🎒 looted bodies, ♠️ poker wins). Selecting a game persists locally and changes the home panel. Missing data says unavailable; achievement percentage is explicitly not campaign completion. Unknown future GTA VI data/title IDs are not fabricated.

Navigation: on GTA home, press Up from the top tabs/actions to focus the Xbox panel; OK opens its page. Down returns to the previous top item. Existing tab/card/app navigation remains. The countdown/date behavior, local gallery, neon, YouTube/trailers and other skins stay as before. The Xbox panel remains after the countdown expires.

Connection is optional. User enters their personal OpenXBL API key in a masked TV field (optionally with the Google TV remote keyboard on their phone), presses Connect, and can disconnect/remove it. Store key encrypted with Android Keystore AES/GCM, never in APK/Git/logs, ADB extras or external storage. Cache private data only in app-internal storage; clear on account change/disconnect. Allow no requests before explicit connection. Authenticated requests only to https://xbl.io/api/v2, no redirects; artwork requests only approved Microsoft/Xbox HTTPS CDNs and never carry API headers.

Game list means games returned by Xbox history, not a promise to enumerate purchased-but-never-played licenses. Search is local, case/accent insensitive, with8 rows/page and up to1000 returned games. If history pagination is not exposed by the provider, disclose that the list is the returned history. Only selected game metrics refresh, every15 minutes plus explicit refresh with cooldown. Bound request sizes/pages, honor429, use at most100 API calls/hour, no background polling while the UI is paused. Keep safe cached data with age/status on temporary failure. Cancel stale responses on selection/account changes.

Use existing skin fonts/palette. Format emoji separately with Android fallback when needed. Keep rendering/image decoding/network off the main thread except small cached Canvas/native updates. Native Xbox setup/detail Activity is nonexported in :home.

Release1.7.0-gta.5/code14, same package/key and install-r upgrade; no uninstall or preference clear. Original MIT/credits/recovery files unchanged. Cloud cannot access TV/account key; final provider/device acceptance is performed by user without sending credentials.
